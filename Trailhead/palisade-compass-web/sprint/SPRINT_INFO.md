# Sprint Information

## Last Story ID

**LAST_ID:** 044

This tracks the last assigned story ID. When creating new stories, increment this number and update this file.

---

## Story ID Guidelines

- Stories use incremental IDs: 001, 002, 003, etc.
- IDs are stable and never change once assigned
- When a story moves between BACKLOG/CURRENT/COMPLETED/ICEBOX, it keeps its ID
- Always update LAST_ID after creating a new story
